# VTB-inspired design system

Reference-derived approximations, not official bank tokens: canvas #EEF5FF, surface #FFFFFF, ink #07123B, muted #52658B, primary #0066FF, hover #0056DB, border #DCE7F6. Existing semantic CSS variables remain the source of truth. Spacing uses a 4/8px rhythm; cards 24px, sidebar 30px, selection 24px radius. Shadows remain restrained. Values use tabular numerals.

Typography: installed Segoe UI / Arial with Cyrillic fallback. Attached HTML declares Omega UI VF and static weights, but supplies no redistribution license. User approval to modify the application does not establish third-party redistribution rights; no font binaries or official bank logo were imported. The original project Shield SVG is reused; small navigation SVGs are authored locally. Text attribution identifies a competition prototype. No bank affiliation or approval is claimed.

Primary controls use blue, white text, rounded geometry, hover and visible keyboard focus. Existing disabled and validation states are preserved. Light mode only; no inactive theme control. Desktop sidebar is 286px, tablet 250px; below 768px navigation becomes a modal drawer. Shared capsule animates transform for 360ms and disables motion on mobile or reduced-motion preference.

Evidence: supplied screenshots and HTML. The specified official comparison URL could not be retrieved during research: https://www.vtb.ru/malyj-biznes/otkryt-schet/sravnenie-pakety-uslug/?from=main-page . No scripts, trackers, proprietary illustrations or bank bundles are imported.
