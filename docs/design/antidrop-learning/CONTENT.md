# Контент первого сценарного модуля

`data/learning/course.json` — единственный runtime-источник контента. В него интегрирован модуль `m8_phone_fraud`; прежние семь модулей сохранены. Версия сценариев: `2026-11-01.phone.v3`; версия каталога: `2026-11-01.v4`; проверка источников: 01.11.2026. Все ситуации синтетические; формулировки адаптированы, это не цитаты и не юридическая экспертиза.

Шесть practice-карточек и независимая проверка переноса навыка используют разные ситуации. Итог не повторяет текст или ответы карточек. Это семь различных учебных целей, без заявления о психометрической валидности. Вопрос c5 намеренно содержит правильный выбор «данных недостаточно»: неожиданность звонка, имя и вид номера сами по себе не доказывают мошенничество. Это педагогический вывод из рекомендации независимо проверять сомнительные обращения; ЦБ не классифицировал наш вымышленный звонок.

`source_needed=false` означает наличие проверенного первичного источника для безопасного действия. Это не аттестация эксперта и не постоянная гарантия актуальности. Источник c6 относится к уже обнаруженному чужому списанию: не распространять этот сценарий автоматически на любое раскрытие любых персональных данных. Не обещаем возврат денег, не обвиняем пользователя и не просим вводить реальные секреты. Перед публичным выпуском повторно проверить источники при изменении текста или регулирования.

## Рекомендация для интерфейса

Существующие AppShell, Onest, семантические токены и мобильная сетка сохранены. Сцена показана как короткий диалог звонка или сообщения, затем вопрос с тремя действиями. Нет имитации системного звонка и автозвука. После ответа показан разбор: опасный признак → безопасное действие → ссылка на источник. Финальная независимая проверка идёт после практики. Прогресс подписан словами, состояние ответа передано также текстом. Концепция самостоятельно выбрана и реализована по прямому разрешению пользователя в задании AntiDrop 2.0.
